# alpha.21 启动恢复验收

`0.2.0-alpha.21` 已部署并作为有限验证的 alpha 预发布版本分发。下文区分实现与定向检查、本机升级、真实任务交接和反向发送；其中一项通过不代表其他项通过。

alpha.20 曾观察到后台退出后遗留状态锁、旧 PID 被其他进程复用、启动器误判后台仍在运行。该次后台退出的具体根因仍未知；alpha.21 修复的是后续恢复判断，不声称已确定此前退出原因。

## 实现与定向验证

- WMI 在同一 Windows 用户和 session 固定启动后台。启动器退出后，由 WMI broker 创建的合成进程仍跨工具调用存活。
- 恢复检查结合 owner、service/supervisor lock、PID 创建时刻、state 和实例端点拒绝连接状态，处理同 boot 单锁、双锁及 state 情况；不明时保留现场，不结束进程，也不把复用 PID 当作仍运行的本实例。
- 恢复专项 79 项 PowerShell 检查、后台启动器 3 项 TypeScript 测试、19 项 PowerShell 断言通过。安装恢复/回滚 15 项、binding 15 项及 guards 检查通过。
- TypeScript 全量 346 项首轮结果为 336 pass、1 项 readiness 失败、9 项因未设 CLI 跳过。将一项一秒等待改为等待真实 ready 后，相关定向测试 2/2 通过；另以真实 native CLI maintenance 16/16 补充覆盖，不记为 346 项全量全绿。
- 专门审查报告指定并核实为 `gpt-6.1-sol / high`。首轮两项 P1 已修复；最后两次定向复核未发现可操作问题。
