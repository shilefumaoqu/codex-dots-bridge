# alpha.19 启动与恢复验收

`0.2.0-alpha.19` 为未发布候选。本页记录 2026-10-13 完成的启动修复、隔离验证与本机部署；真实系统重启后的登录自启仍待下一次自然重启核验。

## 已确认问题与最小改动

本次重启后观察到：安装配置的 autostart 为 false，本项目 Startup VBS 不存在；旧外部登录启动器被此前留下的持久暂停标记挡住；本实例还保留着前一次系统启动期间的锁和状态，其中旧 PID 已被其他进程复用。这些证据解释了本次后台未恢复，不能据此推断历史上从未启用过自启。

本轮沿用现有安装及 supervisor 架构：启用本机当前用户登录自启，停用已核实指向同一实例的旧外部登录启动项并保存回滚配置；增加有界的前次启动残锁识别。没有修改对话读取、发送、工具参数、模型、图标或并发逻辑。

## 必须保留的边界

- 首次安装 autostart 默认不勾选；在 Setup 中启用后，Startup VBS 在当前 Windows 用户登录时启动服务，不承诺登录前启动。升级保留原有设置。
- 自动删除残锁须同时确认：service 与 supervisor 锁完整成对、旧状态属于本次 boot 之前、该实例端口拒绝连接、无仍运行的本实例后台、实例身份和文件归属明确。部分锁、同一次 boot、连接或身份不明均保留现场。
- 无锁但有前次 boot 状态时，只有满足对应离线与身份条件才忽略旧状态；不删除任务或凭据，不结束复用旧 PID 的无关进程。
- 元数据以短时快照读取，不在端口和进程检查期间持有文件句柄；删除前再次核对身份及内容。进程查询中的缺失命令行最多按 PID 刷新一次，查询失败仍停止恢复。
- 正常启动和已正常停止的实例保留快速路径；`run --stop` 停止当前实例，下次登录仍按安装设置启动。

## 性能与剩余限制

恢复探针保持 20 秒总超时；代表性真实残锁恢复集成样本总墙钟约 20.30 秒，含进程及回调开销，接近预算，不能承诺每台电脑都在该时间内完成恢复。重复启动及并发停止样本约 1.65 秒、1.8 秒，仅为本机单次样本。

本机 Startup VBS 启动器自身约 2.2 秒退出，这不是 Bridge/Tunnel 全链路就绪时间，后者单独检查确认。没有依据宣称吞吐或端到端速度提高。

本页为构建后的验收回填，不覆写已生成安装包。私人原始证据、机器路径、任务标识和受保护回滚备份留在本机，不进入公开源码。回退只恢复程序和兼容配置，不用旧数据库覆盖新增任务记录。

alpha.18 的工具目录拒绝和原快照故障仍按 [alpha.18 诊断与验收](alpha18诊断与验收.md) 所载边界处理；本轮启动恢复通过不能替代这些分支的真实验收。

## 后续真实回归（2026-10-13）

用户在启动修复后另行授权Dot验证读取、发送和取回回复。使用既定合成测试对话，保持忙碌先返回选择、离线跳过；没有人工打开目标，没有刷新目录、重启服务、修改程序或推送 GitHub。

- **Codex → Dot → Codex 任务交接通过**：稳定编号入队，Events 首次 HTTP 200 接受，Dot 领取一次、保存真实诊断结果，Codex 取回并 ACK。此任务的 completed 表示诊断结果入库，不表示反向发送成功。
- **Dot 读取通过**：官方已保存历史取齐，Dot 报告 10 回合、1 块、28838 字符，末尾 completed / agentMessage。独立本机核对同一读取请求为 completed / native_stored_history，history_source=codex_app_server、stored_history_complete=true、source_complete=false。不声称压缩前或模型完整上下文已取得。
- **反向发送与回传未通过**：Dot 报告一次发送工具调用尝试，宿主返回 `user cancelled MCP tool call`。随后仅查询原编号，返回 `request_not_found`。独立本机核对：没有该编号的 codex_send_message 入站审计或持久发送记录，只存在对应 status 查询；无接受回合、结果回合或实际回复。请求、目标、正文哈希绑定正确，核对时窗口尚有效。不能据错误字符串认定用户点击取消或自动审批拒绝，具体宿主取消原因未取得。
- **性能分段**：入队到事件接受约 1.88 秒；入队到领取约 94.80 秒；官方读取接口耗时 817 毫秒；入队到诊断结果保存约 172.71 秒。这不是完整发送往返耗时，发送回执和回复等待没有实测值。本次主要前段等待发生在通知接受后、领取之前，不能据单次样本定位平台内部原因。
- **运行保持**：收尾 MCP 核对 alpha.19 服务可达、Tunnel ready、订阅有效；两个其他待回答任务保留。没有重发、换号或恢复旧试验，未进行额外忙碌/离线注入。

结论：本轮提供了新版正向任务交接和官方历史读取的真实回归证据；发送在进入本机 Bridge 之前受阻，尚不能确认新版完整反向往返通过，也没有证据将该宿主取消归因于启动修复。准确请求标识与原始回执留在本机私有验收记录。
