# 兼容性与已知限制

`0.2.0-alpha.7` 是 Windows 10/11 x64 预发布版本，支持单本机用户、单现有 Dot、单任务 FIFO 执行槽。单文件 Setup 内含 Node 运行时与生产依赖；安装生命周期和真实连接的实际验收以该版本 Release 记录为准。旧 alpha.4 不具备本页全部能力。

## 证据范围

| 能力/结论 | 当前证据边界 |
| --- | --- |
| 正反向普通文本闭环 | 既有 glint.7 运行基线有 99 条批次加 1 条补充样本，不能替代新 Setup 验收 |
| 长历史传输 | 既有基线有 667 块、约 2100 万字符完整传输与拼接证明；不等于逐字语义处理 |

| 私有桌面发送 | 实验接口，仅在线空闲一次发送；跨桌面版本兼容与原子忙闲无保证 |
| Setup 安装/升级/卸载 | 自带运行时，操作契约为保留独立用户数据；实际结果查对应 Release 验收记录 |

源码检查、模拟测试、注册文件、服务健康、Tunnel ready、事件 accepted 和完成结果都不能互相代替。未跑的检查保持未验证。

## 本机对话读取

读取走官方本机 App Server，只调用只读 metadata/turns 分页，不恢复、不启动回合，不要求桌面加载目标。read/read-send 须显式启用；local 模式按人类指定本机 thread_id，无逐个登记。旧 targets 配置必须明确迁移，不能假装已放开范围。

持久历史包含官方保存的消息及工具记录，但可能不含原始模型上下文、压缩前材料或未持久化内容。stored_history_complete=true 与 source_complete=false 可以同时成立，必须如实解释。读取上限 60 秒、32 MiB；超限失败而不默默截断。缓存仅优化固定快照分页，释放或重启后不重新读取；新读取请求使用新 request_id。

## 本机对话发送

发送仍依赖私有桌面 IPC，与官方只读接口无关。目标桌面 owner 在线且明确空闲才能投递，读取成功不证明发送可用。写入前复核状态，但与人工同时输入不是原子操作，跨 Codex 版本可能失效。

忙碌、离线、未知永久跳过，不排队、不上线补发、不打断、不恢复目标。发送不明可能已执行，不能换编号重试。只有同 request_id 对应的新回合 exact_turn_reply 是本次结果，不能读取最近回复冒充。

## 权限与安装

使用者仍需自己的 Codex、Dot、Tunnel 权限、专用 runtime key、私有插件和 Events 订阅；订阅登录不能替代 Tunnel 权限。安装不会绕过平台审批。账号功能不可用时保持 pending。

Windows Setup 自带所需 Node 运行时，不要求用户安装 Node/npm；仍需用户现有 Codex。CLI 可作正向 caller；反向发送需要桌面 owner。尚不声称支持 macOS/Linux、多人、多 Dot 或并发执行配置。

本版本 Setup 未签名。下载时核对 GitHub Release 来源与 SHA256；Windows SmartScreen 或组织策略仍可能提示或阻止运行，校验和不能替代发布者签名。访问范围以仓库当前可见性为准；私有仓库需登录有访问权限的账号。

## 数据与恢复

关机、休眠、服务停止不能接收新结果。停止本机程序不撤销云端工作或外部动作。Bridge 的取消是协作停止，不是业务回滚。

默认数据与程序分离，升级/卸载按保留数据的契约执行，实际结果以对应 Release 验收记录为准。恢复仅同账号/Dot，启动前检查 active 订阅与待投递事件；不支持账号迁移。文件链接、外部工具副作用及云端恢复切换需要单独实测。
