## 首版限制

- Windows 10 及以上 x64、单用户、每实例一个 Dot、领取并发 1；不支持跨平台或共享多租户服务。
- 依赖部署者自己的官方 Tunnel 与私有插件权限；源码公开不等于公共插件发布，不承诺账号普遍可用或零费用。
- 无文件托管；外部链接须由 Dot 实际读取。本机文件/应用能力另验，现有 Windows 原生 ACL 初始化问题未被 P0 MCP 成功修复。
- 桥接不能强制停止 Dot 原生工作或撤销外部动作。租约与幂等不提供业务 exactly-once；失租默认待核对。
- Followup 是新建关联任务，不保证原生 thread 接续。事件可能显示在新的 Work/Dot 窗口，结果按 task_id 取回。
- 关闭 Codex 后任务数据仍保留；没有隐藏 IPC、私有 API 或自动恢复已结束回合。可选桌面官方回访需用户明确启用；CLI 不承诺调度管理。
- 本项目不是模型 API SDK、其他 Agent 安装器、应用 webhook 平台或完整网页控制台。


Windows Job进程树自动化测试使用模拟Tunnel；真实中断恢复另见验收记录。安装入口已串联官方接入指引、非秘密元数据、安全文件路径、启动和诊断；官方授权及真实工具调用仍须实际完成。

## alpha.3 发布基线

alpha.3发布基线为0.2.0-alpha.3，运行协议、任务架构和图标沿用现有实现。新增 npm 官方CLI自动识别、公开文件/版本/文档链接检查、许可清单及发布包逐文件校验。已验证Codex原生CLI版本为0.162.0-alpha.2，CI固定该版本；其他版本尚不作为已验证矩阵。换安装目录或CLI原生EXE路径须按[发布与升级](发布与升级.md)先移除旧owned注册并保留数据，再重装。

隔离备份恢复不证明生产云端恢复切换：CLI只检查目标实例已停止，恢复的active订阅会在启动后继续投递。源实例停机和启动前核对原账号/订阅是人工前置，不支持跨账号或不同Dot迁移。

安装与运行采用普通用户终端。管理员终端创建的目录可能归Administrators组所有，并触发untrusted_data_owner；不要通过放宽数据目录ACL来绕过该保护。GitHub托管Windows管理员runner仅在CI测试进程中将新对象默认owner设为当前用户，并验证Node子进程继承；这不构成普通权限的云端验收。

干净Windows环境中守护进程首次C#初始化可能超过15秒，启动预算为45秒。启动命令可能先返回starting；初始化期间请求停止可能返回supervisor_stop_pending，须继续查询，不能当作已停止。运行任务取消的云端确认规则不变。
