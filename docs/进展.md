# 实施进展

更新：2026-10-09。当前源码为 0.2.0-alpha.4 发布候选；最近已发布版本为 [v0.2.0-alpha.3](https://github.com/shilefumaoqu/codex-dots-bridge/releases/tag/v0.2.0-alpha.3)。安装实例的实际版本以 dots_status.version 为准。

## 产品与已实现能力

Codex Dots Bridge 面向 Windows x64、单用户、每实例一个现有 Dot。Codex 使用 stdio MCP 与 Skill，Dot 经官方 Secure MCP Tunnel 和 MCP Events 领取任务、请求澄清、报告检查点并回传结果。

- 九个 caller 工具、八个 worker 工具，以及 Events 列举、订阅和取消订阅。
- SQLite WAL、输入 revision、业务幂等、单执行槽、租约、事务 outbox、签名事件与持久订阅。
- 原任务澄清续接、处理中补充、关联追问、协作取消、结果读取和取回确认。
- caller/worker 分离认证、环回 Host/Origin 检查、回调地址验证、Windows ACL、实例锁与后台进程树保护。
- Windows 私有 Node 24.21.0、官方 Tunnel 0.0.16、安装与维护入口、受保护备份恢复、保留数据卸载。
