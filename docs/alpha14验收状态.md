# alpha.14 候选验收状态

`0.2.0-alpha.14` 是 Windows x64 未发布候选。本轮隔离回归、专门审查、构建和同一 Setup 的隔离新装、alpha.13→alpha.14 升级、重复安装、回退及卸载保留数据已通过。按本轮决定保留当前任务与服务，本机仍运行 alpha.13；新版本部署、客户端/Dot目录采纳及真实往返暂缓。实际运行版本以 `dots_status.version` 为准。本页记录分层验收，不替代 Release。alpha.12/13 历史结论保留在[alpha.12 状态页](alpha12验收状态.md)与[alpha.13 状态页](alpha13验收状态.md)。
