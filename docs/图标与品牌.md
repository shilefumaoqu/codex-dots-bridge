## 使用位置

| 位置 | 素材 |
| --- | --- |
| 插件主图标 | 素材/星渡/星渡-应用.png，512×512；另提供 SVG |
| README、小尺寸展示 | 素材/星渡/星渡-应用-128.png，另备256×256 |
| 浅色底透明图形 | 素材/星渡/星渡-图形.svg / .png |
| 深色底透明图形 | 素材/星渡/星渡-图形浅.svg / .png |
| 浅色聊天入口 | 素材/星渡/星渡-单色深.svg |
| 深色聊天入口 | 素材/星渡/星渡-单色浅.svg |

应用版使用深炭黑 #191C22、浅白 #F5F8FF、浅金 #F3CF85；浅底透明版采用深炭黑和深金 #AF8130。十个 PNG/SVG 共用同一造型。插件 manifest 可分别引用 logo、logoDark、composerIcon、composerIconDark；插件包和桥接程序独立计版本。

## 平台显示边界

列表页与详情页可能使用不同图标来源。已有列表加载素材一致的验证记录；详情页曾显示平台默认图标，聊天入口深浅色显示未独立验收。上传及回读素材不能代替各页面实际显示验证。
