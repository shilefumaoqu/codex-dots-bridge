应用图标采用深炭黑 #191C22、浅白 #F5F8FF、浅金 #F3CF85；浅底透明版采用深炭黑与深金 #AF8130。插件配置可按平台字段选用相应素材，私有插件配置与桥接程序独立维护。

上传素材、manifest 回读和平台实际显示是不同检查。列表、详情页及深浅主题入口需要分别观察，不从文件存在推断各界面显示成功。Setup 图标及安装界面须随对应安装包实际验收，结果以该版本 Release 记录为准。
