# 星渡 · 图标与品牌

Codex Dots Bridge 使用星渡深炭黑图标，随本项目 MIT 许可提供。

当前源码版本见 [package.json](../package.json)，实际运行版本及验收范围见鉴权服务状态和 [ACCEPTANCE.md](../ACCEPTANCE.md)。历史 `0.2.0-alpha.21` 保持 Codex Dots Bridge 图标与产品标识，当时已完成最终包安装验收与生产部署；其正向任务及反向单样本的结果与限制见[alpha.21 启动恢复验收](alpha21启动恢复验收.md)。托盘与品牌素材的 alpha.20 记录保留在[alpha.20 托盘验收](alpha20托盘验收.md)，本轮未重新生成或替换图标。

应用图标采用深炭黑 #191C22、浅白 #F5F8FF、浅金 #F3CF85；浅底透明版采用深炭黑与深金 #AF8130。插件配置可按平台字段选用相应素材，私有插件配置与桥接程序独立维护。

托盘按三行显示本地服务、云端连接和 Dot 订阅，并用 green、amber、red、gray 配合文字表达就绪、待确认、故障和正常停止。版本不一致用 amber，并分别列出当前 CLI 与实际运行服务版本；服务版本未取得时保留未知。状态色表达当前连接观察，不代替任务执行或完成回执。右键菜单直接勾选登录自启，退出只关闭界面。

上传素材、manifest 回读和平台实际显示是不同检查。列表、详情页及深浅主题入口需要分别观察，不从文件存在推断各界面显示成功。Setup 图标及安装界面须随对应安装包实际验收，结果以该版本 Release 记录为准。
