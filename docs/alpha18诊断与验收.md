## 本轮改动

- 复用内部 task_evidence，记录固定工具名、合法 UUID、服务版本、received/responded 和 HTTP 状态。worker_protocol_response 与原 request 事件分开，不重复计算原请求。
- IPC 仅失败时记录固定错误子类、帧大小与匹配计数，区分接收缓冲限制、帧大小、UTF-8、JSON、连接关闭和快照超时。原公开状态及错误码不变。
- 正文、密钥、路径、原始帧和未允许字段不进入诊断导出；诊断异常不能改变调用、重复发送或替代实际回复。
- 保留 alpha.17 自动加载、官方分页读取、忙碌由人选择、离线跳过、原请求去重、精确回合回复关联及正向任务链路。
