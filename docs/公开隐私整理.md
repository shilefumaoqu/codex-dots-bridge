# 公开资料隐私整理

更新：2026-10-09。适用候选：0.2.0-alpha.4。

## 本批内容

公开文档移除与产品无关的私人使用渠道、其他个人项目关联、对话原文、登录/授权排障过程、设备运行经历和私有插件元数据更新故事。保留产品契约、合成输入、版本化测试证据、失败及未验证边界。中英文 README 具有相同章节、命令和能力说明。

源码与安装包不包含预绑定的开发者账号、Dot、Tunnel、运行密钥、数据库或真实任务资料。公开仓库地址、维护者公开 GitHub 署名和第三方来源仍属于正常公开元数据。

## 验证范围

本批为文档、版本标识和重新打包整理，运行逻辑与数据库 schema 沿用 alpha.3。既有96项测试和真实 Dot 合成任务证据分别保留，不自动转为本批新增真实验收。独立公开分支构建与96项测试通过，零失败、零跳过，包含实际官方CLI安装覆盖。源码检查84文件、零失败，中英文命令/标识/链接一致；Windows包3841文件、59项npm许可校验通过。独立只读文档复核确认十条合成输入、37分钟观察、19条任务（17完成/2取消）及未验证项保持；本批不涉及逻辑修改，不新增专门代码审查。GitHub CI与远端发布状态以对应Release实际记录为准。

## 历史边界

当前分支的清理不会自动删除旧提交、旧 Tag、PR 差异和旧下载包中的文档。历史处理需遵循仓库维护者确认的范围；此前下载的副本和第三方缓存也不能保证被收回。发现真实秘密时先撤销/轮换，再处理历史，不能仅删除文字。
