# 托盘订阅检查

本候选沿用现有托盘自动刷新：窗口展开时约每 5 秒、隐藏时约每 15 秒读取一次本机鉴权状态。查询不发送任务，不创建或续期订阅，也不新增周期 Node 状态进程。

## 日常使用

- **订阅有效**：显示本机服务记录的有效期。平台续期成功并保存后，托盘会自动更新。
- **即将到期**：剩余两小时以内显示黄色，等待平台正常续订，不弹提醒。
- **订阅已失效／无有效订阅**：可靠状态确认后，本次失效期间只尝试显示一次本机提醒。Windows 是否展示通知取决于系统通知设置；恢复后静默更新。
- **状态未知**：超时、身份或版本不一致、旧服务缺少新字段等情况保留未知；不会把上次有效期当成本次失效证据。

使用 **检查并处理订阅** 可以立即重新核验。若状态已经恢复，就显示新结果；若仍确认失效，则打开你保存的原规则。第一次在托盘中保存原规则的 HTTPS 链接，之后不用反复寻找。链接只能指向 `chatgpt.com` 下的 `scheduled/automation/` 规则详情，不接受带凭据、查询参数或其他站点的链接。

本候选只验证了上述链接格式和显式点击行为，尚未验证真实账号页面是否采用该路径。链接需要来自用户已打开的原规则，不能由 Bridge 猜测规则 ID；真实页面直达仍是部署前待验项。官方的[任务管理说明](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt)介绍了在 Scheduled 中管理原任务，本候选不把该说明当作续订 API 或规则直达路径的证明。

打开页面不等于续订成功。需要平台恢复监听时，在原规则页面按其实际提供的入口操作；托盘继续自动检查新的服务回执。Bridge 不模拟平台调用 `events/subscribe`，不修改数据库日期，不自动暂停／恢复规则或反复重装连接。打开页面仍遵守系统浏览器和平台的权限限制。

## 运行实例核对

托盘校验本地配置、运行锁、鉴权响应、实例、版本、时间和数据目录指纹。即使两个隔离副本沿用了同一个实例 ID，它们也不能只凭 ID 相同通过本次目录绑定检查。状态窗提供当前数据位置供核对；复制诊断不会带上该私人路径、原规则链接或凭据。

这不等于自动寻找并合并所有历史数据目录，也不能阻止未升级的旧程序从另一处目录启动。复用同一 Tunnel 做候选测试时，仍须按维护流程保证只有一个运行实例，并保存当前结果。不能用旧库覆盖已接纳新工作的候选库。

## 本地偏好与边界

原规则链接及提醒去重仅保存在数据目录旁的托盘偏好文件中，不写入业务数据库、订阅记录或服务配置。它们不随业务备份恢复自动复制；恢复到另一目录后需要重新核对规则绑定。不要把私人偏好文件提交到源码或公开发布包。

检查和处理入口不会自动启停服务、切库、重放事件、重新发送旧任务或清理 unknown。HTTP 200、订阅有效和托盘绿色都不能代替 Dot 实际领取与准确回复证据。

本候选的隔离测试只覆盖投影、绑定、刷新、提醒去重及入口行为。Windows 通知实际展示、用户账号的原规则操作、自然续期和长期稳定性须分别验收，不能以合成状态或打开页面宣称完成。
