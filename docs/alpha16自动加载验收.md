# alpha.16 自动加载与授权来源验收

本候选仅修正自动加载脚本的省略参数默认值；显式非法参数、原进程身份核验、单次导航、在线/忙闲复核及发送去重保持原实现。

云端 Events v2 缺少服务 v6 的 caller 来源解释，且仍要求忙碌直接跳过。原订阅已在官方界面更新为入口规则 v3，完整回读一致；原生审批、两个 false 字段、订阅和触发器保持。一次真实试验确认采用入口 v3/服务 v6，并实际调用 send/status 各一次，没有重复授权或实际宿主拒绝；旧运行版返回 native_autoload_unavailable，没有原生回合或回复。不能据此宣布反向闭环通过。

已安装脚本默认参数 Probe 失败，显式同脚本目录 Probe 成功；独立只读诊断支持默认目录解析为直接根因，不宣称具体 PowerShell 内部缺陷。修正版仅在 WorkingDirectory 未绑定时在脚本正文取 PSScriptRoot。真实 Windows PowerShell 5.1 -File 隔离 Probe 及既有包装器合计 6 项通过，显式空值/相对/引号/换行仍拒绝。typecheck 与修正版真实只读 Probe 通过。gpt-6.1-sol / high 专门只读审查无范围内问题，内部实际模型未核实。

新包构建与相同 EXE 的全新安装、alpha.15 → alpha.16 升级和卸载保留数据已通过。本机已切换 alpha.16，程序注册、Skill 和加载脚本匹配安装内容；102 条升级前任务原样保留，访问设置、凭据、实例和原订阅保留。首次安装因私有维护脚本误传启动目录而在写入前拒绝；按原安装记录修正参数后成功。该私有脚本问题未修改产品安装器，不覆盖失败证据。

修正版真实往返仍未通过。Dot 采用 Events 入口 v3、服务 v6 与 alpha.16，实际调用 send/status 各一次，没有重复授权问题或观察到实际宿主拒绝；完成的是诊断结果，未获得原生回合与回复。首次原生入口查找约 10 秒，导航接受约 0.75 秒，第二次原生入口查找仍明确 no-client-found，返回 native_owner_unavailable_after_load，总计约 20.82 秒。导航 ACK 不等于目标加载成功。稍后单次只读 owner 查询约 4 毫秒取得入口，但不能排除这段期间的人工操作或其他加载变化，也不能确定注册何时出现；不据此扩大超时或声称完整往返通过。
