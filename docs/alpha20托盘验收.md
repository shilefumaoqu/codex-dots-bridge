# alpha.20 托盘验收

`0.2.0-alpha.20` 为待发布的 Windows x64 alpha 候选。此页只保留通用结果；安装环境、原始回执、账号、任务与对话身份留在私有记录中。安装载荷内的文档是构建时快照，最新结果以此页和最终安装器摘要为准。

## 本次实现

- 轻量 .NET Framework 4.8 托盘与无边框状态窗，显示本机服务、云端连接、Dot 订阅；右键切换登录自启，退出托盘不停止后台。
- 分别读取托盘、安装程序和鉴权服务版本；版本不一致或状态不明显示黄色，不根据 PID 存活宣称就绪。
- 升级统一切换同实例的后台、托盘、Startup 和开始菜单。待处理任务阻止停机；回退恢复程序与兼容配置，不用旧数据库覆盖新任务。
- 主快捷方式直接运行托盘 EXE，并显式传入安装解析的数据目录，移除旧入口的隐藏 PowerShell/ExecutionPolicy Bypass 包装。失败回退恢复原快捷方式，保留用户修改。
- 保留现有 Codex→Dot、官方分页历史读取、实验性桌面发送、忙碌选择、离线跳过与发送不明不自动重试。

## 剩余问题与发布边界

- 曾观察到后台退出后留下状态锁，同次开机旧 PID 被其他进程复用，导致启动器误判后台仍运行。已核对归属并恢复现场，退出根因及此场景自动恢复尚未修复。不能把恢复操作记作持久修复或长期稳定性通过。
- 首次安装曾返回通用 `bridge_operation_failed` 并正确回退；同一安装包后续诊断安装成功，初次异常的底层原因仍未确认。
- 旧快捷方式被安全软件拦截；新直接 EXE 入口已本机回读并保持存在。未关闭防护或加白名单，不保证所有安全软件不报。
- alpha.20 尚无新包的 Codex→Dot→Codex 和 Dot→原对话→Dot 完整业务验收；历史版本的通过证据不替代本批。
- 当前用户真实登录/重启、系统多屏、高对比、长期常驻尚未验收；当前回合追加不支持，并发仍为 1。
- 截至本次整理，未推送代码、创建 Tag 或发布 alpha.20 Release。现有发布证据门禁尚未全部满足，不能标为发布就绪。
