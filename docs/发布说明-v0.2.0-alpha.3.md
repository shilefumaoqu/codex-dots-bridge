# Codex Dots Bridge v0.2.0-alpha.3

Windows x64 预发布：在 Codex 对话里委派文本任务给自己的 Dot，沿 task_id 处理澄清、补充、进度和结果回传。

## 本次更新

- 修复干净Windows环境下守护进程初始化超过原15秒启动预算的问题；启动最多等待45秒，启动中停止可能返回pending，需再查询实际状态。

- 修复官方 npm Codex CLI 的自动识别，支持 nested、hoisted 和 vendor 原生 EXE 布局。
- 桌面升级删除旧 CLI 时，可用 `uninstall --codex-command 新原生EXE` 核对并移除原 owned 注册；保留其他 MCP/Skill 和任务数据。
- 完善先初始化再保存 Tunnel 密钥、可信下载包校验、脚本执行、升级回退和恢复边界。
- 安装包包含固定 Node 24.21.0、官方 Tunnel 0.0.16、锁定生产依赖和完整第三方许可清单。
- 增加源码公开检查、版本/文档链接检查、逐文件 release manifest 与 ZIP SHA256；源码归档无 `.git` 也可检查和构建。
- 保留星渡深炭黑图标、现有 UI、任务契约、双 MCP、SQLite 和 Events 架构。

## 下载与安装

本次 Release 提供：Windows x64 ZIP、同名 `.sha256` 和源码 ZIP。下载核对来源及 SHA256，解压到用户可写固定目录，按 README 和快速开始先校验，再运行 `scripts/install.ps1`。普通包安装不需全局 Node 或 npm 构建。

Codex 保持订阅登录，但 Tunnel 运行密钥、Tunnels 权限、工作区关联及自己的私有插件/Dot订阅仍须首次配置；不承诺仅有 Codex 订阅即可零配置连接。安装完成不等于工具或真实任务闭环通过。

## 本机验证

- 类型检查与编译通过；干净无Git源码副本真实安装依赖、构建和96项回归通过，源码安装无需额外C++编译工具链。
- 96 项自动化测试通过，零失败、零跳过，包含真实官方 CLI 的隔离注册/卸载；合成 worker 不算真实 Dot 验收。
- Windows PowerShell 5.1、仅 npm CLI、含空格/中文/单引号数据路径的隔离安装、重复安装通过。
- 实际解压包的完整性、服务启动、按原 ID 重启读回、离线备份恢复、卸载保留数据库通过。
- npm audit 全部锁定依赖目前报告零已知漏洞；这不是无漏洞保证。
- 专门 Codex review 使用 gpt-6.1-sol / high，确认的源码归档、路径和测试前置问题已修复并回归。

既有真实 Dot 文本链路证据延用，该发布批次没有新增真实Dot业务验收。远端构建结果见 [GitHub Actions](https://github.com/shilefumaoqu/codex-dots-bridge/actions/workflows/ci.yml)。维护者在 CI 通过后创建 Release，并核对上传资产与校验文件。

## 已知边界

自然订阅续期、长期稳定性、登录自启、可选桌面回访、云端恢复切换、文件和外部业务操作仍未验收。恢复仅支持同一账号/同一 Dot，原实例须完全停止，启动前核对保留的 active 订阅；不支持跨账号迁移。平台不同页面的图标来源可能不同：验收样本的列表素材一致，详情页曾显示默认图标。

当前是 alpha 预发布，不能替代 v1.0 稳定验收。源码采用 MIT；第三方按各自许可分发。
