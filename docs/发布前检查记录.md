## 交付候选

源码与运行程序版本 `0.2.0-alpha.3`；Windows x64 ZIP 包含私有 Node 24.21.0、锁定生产依赖、官方 Tunnel 0.0.16 完整目录。平台私有插件与桥接程序独立计版本；发布包不包含预绑定身份。本批在隔离环境验收。

## 检查与修复

- 官方 npm CLI 自动识别原生 EXE，覆盖 nested/hoisted/vendor，避免直接通过 shell 执行 cmd 包装器。
- 支持旧 CLI EXE 已删除时显式指定新 CLI 卸载；仍严格比对 owned MCP 注册，保留外来/修改的配置。
- 安装说明明确先初始化再保存密钥、账号权限、可信包校验和脚本执行；doctor 能力说明收窄到当前实际实现。
- 补齐升级回退、同账号离线恢复、active订阅启动即恢复投递、源实例停机须人工确认的边界。
- 构建复用现有 PowerShell 和 npm lockfile，加入版本化不可覆盖命名、许可清单、逐文件 manifest 和 ZIP SHA256，CI不自动发布。
- 保留 MIT，补准确直接依赖来源及完整传递依赖声明；两个npm包缺少独立正文，补收录其上游原许可。完整Node/Tunnel伴随声明保留。
